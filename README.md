# 🟩 🟨 ⬛ Wordle Skills ⬛ 🟨 🟩

Welcome to **Wordle Skills**! This is an interactive, mobile-friendly clone of the famous word-guessing game, built completely from scratch using web code. It is designed to be played smoothly on an iPad touch screen or a computer keyboard.

---

## 🎮 How to Play

You have **6 tries** to guess a secret **5-letter word**. Each time you make a guess, the color of the tiles will change to show how close your guess was to the word:

*   🟩 **Green Tile:** The letter is in the word and in the **correct** spot.
*   🟨 **Yellow Tile:** The letter is in the word but in the **wrong** spot.
*   ⬛ **Grey Tile:** The letter is **not** in the word at all.

---

## 🚀 Special Features Built In

*   📱 **Fully Responsive Layout:** Optimized specifically for iPad web browsers with responsive scaling.
*   ⌨️ **Dual Input Support:** Features an interactive on-screen virtual keyboard for touch control, plus physical keyboard listener logic.
*   ⚡ **Instant Feedback:** Automated message alerts appear when words are too short or when the game concludes.
*   🧠 **Vocabulary Builder:** A hand-picked dictionary file focusing on essential English words and coding terminology.

---

## 🛠️ Built With

This project relies purely on vanilla web technologies without any heavy frameworks:

*   **HTML5** - Semantically structured game boards and virtual keys.
*   **CSS3** - Custom flexbox/grid layout and distinct color schemes matching the original Wordle design.
*   **JavaScript (ES6)** - State management for guess rows, input validation, and character tracking.
